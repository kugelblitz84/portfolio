The product and my part in it.

A full-stack platform for digitalizing club operations, member management, event workflows, realtime communication, and competitive programming contest tracking.

02 / My contribution

From decisions to implementation.

  • Built event/member management, event gallery, admin chat, FCM push notifications, and contest tracking for 30+ competitive programming platforms.
  • Implemented JWT/OTP authentication, role-based access control, Zod request validation, automated PDF generation, email workflows, and scheduled background tasks.
  • Designed the mobile app with Flutter/GetX and built backend APIs with Express 5, MongoDB, Mongoose, Socket.IO, Cloudinary, Puppeteer, Nodemailer, and Agenda.
