01 / Overview

The product and my part in it.

A realtime AI voice tutor where I helped move the project from an expensive prototype to a more practical Pipecat + LiveKit architecture, then implemented the Flutter app flow from Figma.

My role

Researched alternatives, migrated the architecture, solved WebRTC deployment limitations, stabilized async backend operations, deployed on Railway, and implemented the Flutter frontend after prototype validation.

02 / The challenge

What needed to change.

The prototype used GPT Realtime API, which was not compatible with the cost margin at roughly $40 per 1,000 minutes. The project needed a cheaper architecture while keeping realtime voice interaction feasible.

03 / My contribution

From decisions to implementation.

  • Migrated the voice architecture from GPT Realtime API to a Pipecat + LiveKit based solution.
  • Reduced estimated realtime voice cost from about $40 to $14 per 1,000 minutes by limiting paid usage mainly to STT/TTS services.
  • Implemented FastAPI session orchestration with LiveKit token generation, session start/end flow, and bot worker lifecycle handling.
  • Solved LAN-only WebRTC/STUN deployment limitations by moving to LiveKit-supported realtime transport.
  • Split unstable async service flow into separate session/token and bot-worker services to improve Railway deployment stability.
  • Connected the Flutter app flow with realtime session handling and implemented UI from Figma.

04 / The outcome

Estimated cost: $40 → $14

Reduced estimated voice cost from about $40 to $14 per 1,000 minutes and addressed realtime transport and deployment stability.
